# HSdeck Rise Of Shadows 카드 API

`cards.json`과 `render.json`은 기존 HS Plus 카드 정보를 기반으로 하며, `art/`는 설치된 클라이언트의 원화입니다. `golden/`은 해당 카드의 원본 황금 원화 재질·애니메이션·텍스처입니다. 날짜별 과거 원화나 황금 효과를 보장하지 않습니다.


## API 편집·경량화 규칙 (2026-11-14)

- 공개 자료는 `cards.json` 카드 목록, `data/<CARD_ID>.json` 한국 날짜별 카드 정보, `art/` 일반 원화, `golden/` 황금 원화·애니메이션 및 `frame/` 프레임/셰이더/텍스처로 한정합니다. 리소스의 ID·파일 경로·바이너리 원본을 보존합니다.
- `render.json`, `history.json`, `*-date.json` 같은 중복/호환 집계물은 다시 커밋하지 않습니다. 빌더가 만든다면 검증용 임시 출력으로만 사용합니다.
- 카드별 날짜 키 형식이 아니면 최초 한국 대전 가능 날짜·후속 변경분을 검증해 무손실 변환합니다. 베타는 북미 사용 시각의 한국 날짜, 모험모드는 실제 지구 개방, 이벤트는 실제 개시일입니다. 토큰과 선택지까지 포함합니다.
- 잘못된 기존 날짜는 추가 키만 만들지 말고 삭제·통합합니다. 변경일에는 실제 바뀐 필드만 넣고 표시 줄바꿈은 `<br></br>`로 통일합니다. 추정치를 확정 스펙으로 승격하지 않습니다.
- 원화·황금·프레임 데이터의 무손실 보존이 우선입니다. 재생성에 사용하는 `release-policy.json`, `tools/`, `.github/` 등의 실제 의존성을 확인한 후에만 추가로 정리합니다.
